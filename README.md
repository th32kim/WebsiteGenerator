# AI Website Generator

**Introduction.** This project is a full-stack **Next.js (App Router)** application that turns natural-language UI requests into **streaming**, **structured HTML** suitable for a live preview: the backend exposes **Route Handlers** that proxy **OpenRouter** using OpenAI-compatible chat completions, **parses Server-Sent Events** on the server, and streams text to the client; the playground extracts fenced markup, injects it into a **sandboxed iframe**, and supports **human-in-the-loop refinement** via click-to-select, inline editing, and Tailwind-focused side panels—persisting the **edited DOM**, not just the raw LLM string, through **`POST /api/frames`**. User identity and optional plan rules use **Clerk** (`currentUser` / `auth()` on the server, protected routes via middleware), while **Neon PostgreSQL** and **Drizzle ORM** model **users**, **projects**, **frames**, and **JSON-backed chat** so workspaces can list and reopen prior generations end-to-end.
